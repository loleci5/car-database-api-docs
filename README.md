**RevCarData** is a structured vehicle specifications database and REST API for
developers, marketplaces, dealers, insurers, fleets and data teams. The current
release contains **454,431 vehicle configurations**, **294 makes**, **8,927
make/model combinations** and **53 published specification fields**.

Use the API for live lookups, or license the cleaned CSV/JSON dataset for
analytics, imports and internal products.

## What you get

- **Vehicle identity:** make, model, year, generation, trim and body type.
- **Specifications:** engine, power, torque, transmission, drivetrain,
  dimensions, weight, fuel consumption, CO₂ and performance.
- **EV/hybrid fields:** battery capacity, electric range and fuel type where the
  source publishes them.
- **Stable records:** stable vehicle IDs and a natural key for repeatable joins.
- **Monthly refresh:** generated by a repeatable cleanup and quality pipeline.

## Quick start

Base URL:

```text
https://api.revcardata.com
```

Send your API key in the `X-API-Key` header:

```http
X-API-Key: YOUR_API_KEY
```

Get a key at [revcardata.com/pricing](https://revcardata.com/pricing/).

### Python

```python
import requests

response = requests.get(
    "https://api.revcardata.com/api/v1/vehicles",
    params={"make": "Toyota", "year": 2024, "limit": 10},
    headers={"X-API-Key": "YOUR_API_KEY"},
    timeout=30,
)
response.raise_for_status()
print(response.json())
```

### JavaScript

```javascript
const params = new URLSearchParams({
  make: "Toyota",
  year: "2024",
  limit: "10",
});

const response = await fetch(
  `https://api.revcardata.com/api/v1/vehicles?${params}`,
  { headers: { "X-API-Key": "YOUR_API_KEY" } },
);

if (!response.ok) throw new Error(`API error: ${response.status}`);
console.log(await response.json());
```

### cURL

```bash
curl --get "https://api.revcardata.com/api/v1/vehicles" \
  --data-urlencode "make=Toyota" \
  --data-urlencode "year=2024" \
  --data-urlencode "limit=10" \
  -H "X-API-Key: YOUR_API_KEY"
```

## Endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| `GET` | `/api/v1/vehicles` | Search and filter vehicles |
| `GET` | `/api/v1/vehicles/{id}/core` | Core specifications |
| `GET` | `/api/v1/vehicles/{id}/premium` | Premium specifications |
| `GET` | `/api/v1/vehicles/{id}/images` | Vehicle images where available |
| `GET` | `/api/v1/vehicles/vin/{vin}` | Decode a VIN |
| `GET` | `/api/v1/makes` | Makes, optionally filtered by year |
| `GET` | `/api/v1/models` | Models by make and year |
| `GET` | `/api/v1/trims` | Trims by make, model and year |
| `GET` | `/api/v1/years` | Available model years |
| `GET` | `/api/v1/body-types` | Body type values |
| `GET` | `/api/v1/fuel-types` | Fuel type values |
| `GET` | `/api/v1/transmissions` | Transmission values |
| `GET` | `/api/v1/drivetrains` | Drivetrain values |
| `GET` | `/api/v1/engine-types` | Engine type values |
| `GET` | `/health` | API and index health |
| `GET` | `/data-quality` | Current row and coverage counts |

## Filter examples

The vehicle search endpoint supports parameters including:

- `make`, `model`, `year`, `trim`
- `body_type`, `fuel_type`
- `min_hp`, `min_ev_range_km`, `max_acceleration_0_100`
- `limit` and `skip`

Example EV search:

```bash
curl --get "https://api.revcardata.com/api/v1/vehicles" \
  --data-urlencode "fuel_type=Electric" \
  --data-urlencode "min_ev_range_km=400" \
  --data-urlencode "limit=20" \
  -H "X-API-Key: YOUR_API_KEY"
```

## Data quality

The current release reports:

- zero duplicate natural keys and zero duplicate stable IDs
- 100% core-field coverage for make, model, year and fuel type
- explicit missing-value reporting instead of invented specifications
- monthly release metadata

Read the public [data quality report](https://revcardata.com/vehicle-data-quality/)
before integrating. Coverage varies by market, model year and trim.
